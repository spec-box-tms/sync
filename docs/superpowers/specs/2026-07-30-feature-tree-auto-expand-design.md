# Автоматическое раскрытие дерева фич

## Цель

При переходе к фиче по параметру `feature` в URL дерево активного среза раскрывает все группы на пути к этой фиче.

## Решение

`FeatureTree` получает код активной фичи, находит все узлы пути к ней и добавляет их в единый набор раскрытых узлов. После этого дерево отображается только по этому набору: переход не удерживает путь раскрытым и не меняет состояние других узлов.

## Поведение

- Изменение `?feature=...` раскрывает все предки выбранной фичи, сохраняя текущее состояние остальных узлов.
- Любой узел, включая предка выбранной фичи, можно свернуть вручную после перехода.
- Если фича отсутствует в активном дереве, набор раскрытых узлов не меняется.
- URL, модель `FeatureTreeNode` и сервис активной фичи не изменяются.

## Проверка

Добавить компонентные тесты: переход раскрывает путь, ручное сворачивание выбранного пути сохраняется, а переход к другой фиче не сворачивает остальные ветки.
