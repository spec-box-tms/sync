# Автоматическое раскрытие дерева фич

## Цель

При переходе к фиче по параметру `feature` в URL дерево активного среза раскрывает все группы на пути к этой фиче.

## Решение

`FeatureTree` получает код активной фичи и передаёт его рекурсивно каждому `FeatureTreeNode`. Узел считается автоматически раскрытым, если код есть среди его прямых фич либо в любом дочернем узле. Ручное раскрытие остальных узлов сохраняется.

## Поведение

- Изменение `?feature=...` раскрывает все предки выбранной фичи.
- Если фича отсутствует в активном дереве, раскрытие не меняется.
- URL, модель `FeatureTreeNode` и сервис активной фичи не изменяются.

## Проверка

Добавить компонентный тест: при передаче кода фичи из вложенного узла отображаются все узлы пути и сама фича.
